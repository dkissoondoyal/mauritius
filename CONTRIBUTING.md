# Contributing

Thank you for your interest in civic technology and democratic participation in Mauritius.

At this stage the repository is **documentation-first**. You can contribute by opening a GitHub issue with a clearly described accessibility concern, documentation correction, feature proposal or public-interest use case.

Please:
1. Explain the problem and whom it affects.
2. Link to publicly available sources where relevant.
3. Distinguish existing law from proposed reforms and personal opinions.
4. Avoid uploading private correspondence, personal data, credentials, or confidential submissions.
5. Keep discussion respectful, evidence-based and non-partisan.

Code contributions may be considered after reviewed components and licensing are published. Opening an issue does not guarantee implementation. Public contributions are visible to everyone.
