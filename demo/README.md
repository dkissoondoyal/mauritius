# Local legislative consultation demonstration

This is a **new, standalone illustrative prototype**, not an export or copy of the Mauritius.Name WordPress implementation.

## Run

Download `index.html` and open it in a modern browser. No build tools, accounts, network connection or server are required.

## What it demonstrates

- A fictional two-clause legislative reader.
- An accessible form to select a clause and preview a proposed amendment.
- A locally rendered preview using `textContent` rather than interpreting entered HTML.

## Important limitations

- The fictional example is **not enacted Mauritius law**.
- No submission, publication, moderation, authentication, persistence, or server-side validation exists.
- Input is not transmitted or saved. Closing or reloading the page discards the preview.
- This demo is **not** a drop-in WordPress plugin or a production-ready consultation system.
- Never enter real personal data into prototypes.

## Before production use

A real deployment requires a privacy impact assessment, consent and retention policies, anti-abuse controls, server-side validation, accessibility testing, moderation procedures, appropriate legal review, security testing and a defined licence.

The goal is to offer a safe technical starting point for discussion, not to imply that the full public platform has been open-sourced.
